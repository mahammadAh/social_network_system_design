# Social Network System Design

Этот репозиторий содержит **проект System Design социальной сети**, созданный в рамках изучения **курса по System Design**.

Цель данного проекта - продемонстрировать, как можно спроектировать архитектуру крупномасштабной социальной сети с использованием современных принципов распределённых систем.

Проект был разработан в процессе прохождения курса:

**Balun.Courses - System Design**  
https://balun.courses/courses/system_design



# Требования к проекту 



#### Функциональные требования : #
- Публикация постов с фотографиями
- Добавление описания к постам 
- Добавление местополежния к постам 
- Возможность оценивать чужие посты 
- Возможность комментировать чужие посты
- Возможность подписки на других пользователей 
- Поиск популярных мест ( места которые чаще всего указываются как местоположение в постах )
- Возможность просмотра постов в в которых отмечены популярные места
- Возможность просмотра ленты других пользователей ( зайти на его профиль и посмотреть посты которые он делал )
- Своя лента где отображаются посты пользователей на которых ты подписан в обратом хронологическом порядке ( сначала отображаются самые новые посты )
-...

#### Нагрузка : #

  - **Посты :**

     RPS:
     - Write = 10 000 000 * 0.05 * 1 / 100 000 = 5
     - Read =  10 000 000 * 100 / 100 000 = 10 000

     Transcation:
      - id                 36 bytes   
      - created_at         8 bytes
      - user_id            36 bytes
      - location           50 byte
      - description        2500 bytes ( 250 worlds * 5 symb * 2 byte )
      - image_base64       2 000 000 bytes ( 2 MB )
        
      Trafic:
      - Trafic (write) = 5 * 2 003 000 byte = 10 000 000 byte = 10 MB/s
      - Trafic (read)  = 10 000 * 2 003 000 byte = 20 000 000 000 = 20 GB/s
     
     ---

  - **Реакции (Оценка) :**

    RPS:
     - Write = 10 000 000 * 10 / 100 000 = 1 000
     - Read  =  10 000 000 * 100 / 100 000 = 10 000

     Transcation:
       Put reaction :
      - id                 36 bytes   
      - created_at         8 bytes
      - user_id            36 bytes
      - post_id            36 byte
      - reaction           2 byte

       View reaction :     
      - post_id           36 bytes
      - reaction_count    8 bytes  
        
      Trafic:
      - Trafic (write) = 1 000 * 120 byte = 120 000 byte = 120 KB/s
      - Trafic (read)  = 10 000 * 50 byte = 500 000 = 500 KB/s
     
     ---

  - **Комментарии :**
    
     RPS
     - Write = 10 000 000 * 1 / 100 000 = 100
     - Read =  10 000 000 * 100 * 5 / 100 000 = 50 000

     Transcation:
       Put reaction :
      - id                 36 bytes   
      - created_at         8 bytes
      - user_id            36 bytes
      - post_id            36 byte
      - text               200 byte

      Trafic:
      - Trafic (write) = 100 * 350 byte = 35 000 bytes = 35 KB/s
      - Trafic (read)  = 50 000 * 350 byte = 17 500 000 bytes = 17,5 MB/s

     ---
     
  - **Общая нагрузка на систему :**
    
    RPS:
     - Write = 1 105</n>
     - Read =  70 000
    
    Trafic:
      - Trafic (write) = 10 MB/s + 120 KB/s +  35 KB/s = 11 MB/s
      - Trafic (read)  = 20 GB/s + 500 KB/s + 17,5 MB/s = 20.1 GB/s




#### Расчет ресурсов : #

 - **Диски :**

   HDD year capacity = 100 МB/с * 86 400 * 365 = 3 ТB 

   SSD year capacity = 500 МB/с * 86 400 * 365 = 15 ТB

                

   Posts = 20 Gb/s * 100 000 * 365 = 730 000 TB ( 730 петабайт )
    
     данные поста оставляем в реалиционное БД и можем держать на HDD / SSD , но файлы ( фотографии ) выносим в файловое хранилище тут уже нужен дата центр , можно воспользоваться облачными хранлищами 


   Reactions = 620 Kb/s * 100 000 * 365 = 23 TB

     пропуской способности 1 HDD будет достаточно , так что проблема только в памяти если взять диски по 20 TB

     23 / 20 = 1.1 - можно взять с запасом 2 HDD диска по 20 TB


   Comments = 18 Mb/s * 100 000 * 365 = 657 TB

    пропуской способности 1 HDD будет достаточно , так что проблема только в памяти если взять диски по 20 TB

     657 / 20 = 33 - можно взять с запасом 35 HDD диска по 20 TB
